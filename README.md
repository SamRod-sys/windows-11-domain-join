# Lab 4: Windows 11 Installation and Domain Join

## Overview
This lab documents installing Windows 11, joining the machine to an Active Directory domain, and logging in as a domain user in a lab environment.

## Tools Used
- Oracle VirtualBox
- Windows 11
- Windows Server 2022 (Domain Controller)
- Host OS: Windows 11

## Lab Objectives
- Install Windows 11 on a virtual machine
- Join the machine to an Active Directory domain
- Log in using a domain user account

## Steps Performed
1. Installed Windows 11 on a virtual machine
2. Completed initial Windows setup
3. Joined the machine to the Active Directory domain
4. Rebooted the system
5. Logged in using a domain user account
6. Verified successful domain authentication

## Result
- Windows 11 installed successfully
- Machine joined to the Active Directory domain
- Domain user login confirmed

## Notes / What I Learned
- Domain joins require proper network and DNS configuration
- Domain user authentication works only after the machine is successfully joined to the domain.
- Domain user accounts can authenticate on joined machines
